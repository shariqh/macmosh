Unlike `embed-host-script.sh`, its `generate` can refuse, so its output goes into a variable first: `text=$(generate)` stops the script under `set -e` with awk's own message, before anything is compared or written. `--check` then compares with `cmp -s <(printf '%s\n' "$text") "$out"`, and the write is `printf '%s\n' "$text" > "$out"`, so a refused drawing never truncates the generated file. `generate` splits the file into pieces (`tr '>' '\n'`, its last command the `tr | awk` pipeline, so `pipefail` carries awk's exit) and reads them with `awk`.
