## Decisions on the plan's open points

The coordinator's, made with the plan:

1. **The icon is the app's own,** `NSApplication.shared.applicationIconImage`, not a drawing of our own. About then shows what Finder and the Dock show. In dark appearance with the Default icon style that is the light M; with the Dark icon style (macOS 26 and newer) the system gives the dark M. The pull request says so under "Where it differs from the design's text", because the design's section 0 pictures the dark M in dark mode.
2. **If a runner's picture shows a generic icon** and not the M: try `NSImage(named: NSImage.applicationIconName)` once. If that is generic too, leave the image out on that path, keep the words, and report it in the pull request. Do not draw the M from `IconArt` or `LetterM` (step 6's lane).
3. **The version is `MacMoshInfo.version`,** not the bundle's key, so a debug run shows the same words. The driver compares it with the app's `CFBundleShortVersionString`, which proves the two agree.
4. **No new size in `LookSize`:** the icon's 48 points and the gaps are the view's own, literal in the view.
5. **Words:** as "Words, exact" above; the two that are new go to the owner in the pull request.
