# The look, step 6: the M in the menu bar: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the M mark of design section 9 in the menu bar in place of today's system symbols, one mark per state that differs in shape even in one colour, recoloured by macOS for a light bar, a dark bar and the open item; prove it on CI's macOS 15 and 26 runners in light and dark before it merges; and close the three leftovers of issue #183 (one table for the M, a lit tile in the Dark icon style check, `make-icon.sh` checking before it copies).

**Architecture:** One pull request on `look/6-menu-bar-m`. MacMoshKit gains `MenuBarMark` (`Sources/MacMoshKit/Look/MenuBarMark.swift`): a table from each symbol name the model gives to a mark (cells solid, faint or hollow, and a badge), built on `IconArt.mCells`, with section 9's sizes and the words VoiceOver hears today. The model, the board and the log keep today's symbol names; only the label's drawing changes: `MenuBarLabel` draws an `NSImage` from the table and the label shows it with `Image(nsImage:)`. CI gains `scripts/ci/bartool.swift` and `scripts/ci/drive-menu-bar.sh`, which photograph the menu bar in light (the `pictures` job) and dark (the `window-dark` job) and read with a tool whether the system recoloured the mark. The branch's first pushes are that trial: first on today's symbols, then on the mark, with two fallbacks. `LetterM` goes; `IconArt.mCells` is the one table.

**Tech Stack:** Swift 6 package, macOS 15+, SwiftUI and AppKit only, Swift Testing; bash and GitHub Actions for CI.

**Spec:** `docs/superpowers/specs/2026-11-25-look-design.md`: section 9 whole; section 4 ("The picture in the menu bar"); sections 12, 13, 14 (item 6) and 15 where they bind. Issue #183. The chosen picture: `docs/superpowers/specs/look-2026-11-25/menu-bar-mark-m.png`.

**Interfaces:**
- `bartool read <png> <x> <y> <w> <h>`: the rectangle in points from the picture's top-left, at `NSScreen.main?.backingScaleFactor ?? 1` pixels per point (1 on the runners), or at `BAR_SCALE` when that is set in the environment. Prints `read bar=<L> far=<L> mean=<L> inkpx=<n> box=<w>x<h>`. L of a pixel: convert it with `rep.colorAt(x:y:)?.usingColorSpace(.sRGB)` (as `scripts/ci/icontool.swift:75` does; a screenshot carries the display's profile, not sRGB), then the formula `Contrast.luminance` writes in its comment (`Sources/MacMoshKit/Look/Contrast.swift:16-17`, WCAG 2.2, https://www.w3.org/TR/WCAG22/#dfn-relative-luminance), copied into the tool because it is one file and imports only AppKit. `bar`: the median L of the rectangle's outermost ring of pixels. Ink pixels: `|L - bar| >= 0.1`. `far`: the L of the ink pixel farthest from `bar` (`bar` when there is none). `mean`: the mean L of the ink pixels. `box`: their bounding box in points.
- `bartool zoom <png> <x> <y> <w> <h> <out.png>`: that rectangle, 8 pixels per pixel, nearest neighbour.
- Exits 1 when the picture cannot be read or written, 2 on a wrong call. The header says it only reads and never moves the pointer.
- `osascript menu-ax.applescript barinfo` prints `barinfo pos=<x>,<y> size=<w>,<h> axdescription=[…] axtitle=[…] axhelp=[…] axroledescription=[…]` for `menu bar item 1 of menu bar (count of menu bars)` of process "MacMosh": each the `value of attribute "AXDescription"` (and `"AXTitle"`, `"AXHelp"`, `"AXRoleDescription"`) of the item, read one by one in a `try`, `missing value` or an error printed as empty. Never System Events' `description` property: its dictionary (`sdef '/System/Library/CoreServices/System Events.app'`) says it is "the accessibility description, if available; otherwise, the role description", so it is never empty and would turn a role phrase into spoken words.
- `MENU_OUT=<folder> MENU_BAR_APPEARANCE=light|dark scripts/ci/drive-menu-bar.sh`: needs `scripts/build-app.sh --debug` and `dist/debug/menutool`; builds `bartool` into `$MENU_OUT` with `swiftc -O` unless `BAR_TOOL` names one. Writes `pictures/`, `driver.log`, `app-log.txt`, `results.tsv` (the menu driver's format: result, os, sample, check, detail) and a `GITHUB_STEP_SUMMARY` table. `os` is `macos<major>`; every picture name starts `<os>-<appearance>-menubar-`.

```swift
public enum MarkCell: Sendable, Hashable { case solid, faint, hollow }   // a cell not in `cells` is clear
public enum MarkWeight: Sendable, Equatable { case regular, bold }
public enum MarkBadge: String, Sendable, CaseIterable, Hashable {
    case exclamation = "exclamationmark.circle.fill", person = "person.fill", padlock = "lock.fill",
         warning = "exclamationmark.triangle.fill", noEntry = "nosign", wrench = "wrench.fill", plus = "plus"
    public var symbolName: String { get } }                               // rawValue: a system symbol's name
public struct MenuBarMark: Sendable, Hashable {
    public let cells: [IconCell: MarkCell]; public let badge: MarkBadge?
    public init(cells: [IconCell: MarkCell], badge: MarkBadge?)
    public var drawn: Set<IconCell> { get }                               // cells.keys
    /// The nine names the model gives, in the order of design 9's table.
    public static let symbols: [String]
    /// The mark for a name; a name not in `symbols` gets the still-checking mark, which claims nothing.
    public static func of(symbol: String) -> MenuBarMark
    // Design 9, in points, y counted down from the top of the box.
    public static let box = 16.0, inset = 1.0, cell = 2.0, gap = 1.0, cornerRadius = 0.5
    public static let faintOpacity = 1.0 / 3, hollowLine = 0.5
    public static let badgePointSize = 6.0; public static let badgeWeight = MarkWeight.bold
    public static let badgeHole: Set<IconCell>                            // row 3 column 4, row 4 column 4
    public static let badgeRect: CGRect                                   // x 10, y 10, 6 by 6
    public static func cellRect(_ cell: IconCell) -> CGRect               // x = inset + column * (cell + gap), y likewise
    /// Where a hollow cell's line runs: cellRect inset by hollowLine / 2, so the line stays inside the cell.
    public static func hollowRect(_ cell: IconCell) -> CGRect
    public static let hollowCornerRadius: Double                           // cornerRadius - hollowLine / 2 = 0.25
    /// The black's opacity for a cell: solid and hollow 1, faint faintOpacity.
    public static func alpha(_ look: MarkCell) -> Double
    /// A badge symbol of that natural size, scaled to fit `badgeRect`, centred across, standing on its foot.
    public static func badgeFrame(natural: CGSize) -> CGRect
}
```

The table (design 9, and the picture's row of states): `checkmark.circle` the M's thirteen cells solid, no badge; `exclamationmark.circle`, `person.crop.circle.badge.questionmark`, `lock.circle`, `exclamationmark.triangle` and `wrench.and.screwdriver` the M without `badgeHole` solid, with `exclamation`, `person`, `padlock`, `warning` and `wrench`; `wifi.slash` the M without `badgeHole` hollow, with `noEntry`; `ellipsis.circle` the M faint except row 2, whose five cells are solid, no badge; `plus.circle` the M without `badgeHole` faint, with `plus`.

`badgeRect` is where the chosen picture draws the badge's dotted ring: measured on `menu-bar-mark-m.png` (20 pixels per point, the grid's first cell at pixel 80), the ring spans 9.95 to 16.05 points across and down, so 10 to 16.
